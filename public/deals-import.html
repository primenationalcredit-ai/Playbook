📊 Deals Data Import

Import Pipedrive deals into Supabase for unified reporting

📋 How to Export from Pipedrive:

  1. Go to Pipedrive → Deals
  2. Select the filter/view you want to export (or "All deals")
  3. Click Export → Choose CSV
  4. Make sure these columns are included:
    • ID, Title, Owner
    • Pipeline, Stage, Status, Value
    • Doc (1), Final (1), RD1 Start/End Dates
    • Call Center Rep, Person, Organization
    • Add time, Update time, Stage change time
  5. Upload the CSV file below

🔄 After Import

Once imported, your deals will be available in Supabase. The dashboard will automatically read from there instead of hitting Pipedrive API.

Webhooks will keep the data in sync going forward - any deal changes in Pipedrive will automatically update Supabase.
